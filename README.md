# NEMUS | 멀티모달 AI 브랜드 광고

GenAI 기초 2: 멀티모달 콘텐츠 제작 미션 결과물입니다.
가상의 니치 향수 브랜드 NEMUS의 약 40초 광고를 생성형 AI 도구로 기획·제작했습니다.

## 결과물
- 광고 영상: [video/NEMUS_ad_final.mp4](video/NEMUS_ad_final.mp4)
- 스토리보드: [storyboard/NEMUS_storyboard.pdf](storyboard/NEMUS_storyboard.pdf)

## 브랜드 요약
| 항목 | 내용 |
|---|---|
| 브랜드 | NEMUS (네무스), 남녀공용 니치 향수 |
| 슬로건 | 내 곁에, 숲 |
| 타겟 | 도시 생활에 지친 30대 직장인 |
| 핵심 메시지 | 도시 한가운데서, 숲을 입다. |
| 광고 목적 | 인지 (신규 브랜드 런칭) |

## 영상 구성
| 씬 | 내용 |
|---|---|
| S01 | 비 내리는 여의도 출근길 |
| S02 | 지친 사무실 직장인 |
| S03 | 향수를 허공에 분사 |
| S04 | 사무실이 편백 숲으로 변화 |
| S05 | 이끼 낀 숲 오솔길로 몰입 |
| S06 | 향수병 엔딩 카드 (NEMUS / 내 곁에, 숲) |

## 사용 도구
| 분야 | 도구 |
|---|---|
| 기획·프롬프트 | Claude |
| 이미지 | Gemini 이미지 생성 |
| 영상·효과음 | Gemini 동영상 생성 (Veo) |
| 배경음악 | Gemini 음악 만들기 (Lyria 3) |
| 편집 | CapCut PC (통합 편집 용도로만 사용) |

## 폴더 구조
- `storyboard/` 스토리보드 PDF (프롬프트 원문, 수정 전/후 기록 포함)
- `video/` 최종 광고 영상
- `assets/images/` 기준 이미지와 씬별 최종 이미지
- `assets/videos/` 씬별 최종 생성 영상
- `assets/audio/` 배경음악
- 수정 전/후 과정은 스토리보드 PDF의 05·06 항목에 정리되어 있습니다.
